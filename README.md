# Portfolio Page

This is my personal developer portfolio built with React.

I created it to provide a central place to showcase my projects, skills, and transition from hospitality into software development.

Live Site:
https://portfolio-page-nxlr.onrender.com/

The site includes:

- An introduction about me
- Featured projects
- Technical skills
- Links to GitHub and LinkedIn
- Contact information

Building this project gave me additional practice with:

- React components
- Component organization
- CSS styling
- Responsive layouts
- Deploying applications with Render

The goal of this project was to create a simple and professional place to highlight the projects I have built while continuing my software development journey.
